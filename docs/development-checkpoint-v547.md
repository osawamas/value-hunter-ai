# v547 JPXの複数月報と日次権利資料

[実装](https://github.com/osawamas/value-hunter-ai/commit/f56ac6b52dc1698995faa67b9562df6fb76b757b) · [実データ検証](https://github.com/osawamas/value-hunter-ai/actions/runs/43984918087) · [Android回帰](https://github.com/osawamas/value-hunter-ai/actions/runs/43984918076)

- JPX公式の統計月報一覧から「新株落・権利落等一覧」のPDFを発見し、ヘッダーの年月・ページ内の対象行数と照合。固定の列位置に頼らず、銘柄と同じ行の2日付の後から比率を読む。2026年2〜9月の8ファイルを受理し、分割、併合、無償割当てを計199件抽出。1月版は対象7行があるが抽出に失敗し、確認済み月から除外。10・11月版は検証時の目録に未掲載。
- 11月11日の100株10万円以内の仮候補30件に適用。プライム1件とスタンダード2件に期末から取引日までの株数基準変更を検出。残り27件は月報不足で保留。価格や1株指標への比率の自動反映は未実装。
- [日次資料の公式ページ](https://www.jpx.co.jp/listing/others/ex-rights/) から5ファイルへのリンクを検出。最新の旧形式Excel `20261116.xls` を実取得し、217行、対象期間11月16日〜30日、銘柄コード・普通取引の権利落日・備考・更新フラグの列を確認。短期間の予定表なので一回の取得では10月〜11月上旬の不足を埋められない。日次資料の連続保存と改訂照合が必要。分割・併合行の自動抽出は次の工程。
- [J-Quantsのデータ仕様FAQ](https://jpx-jquants.com/ja/help/data) に、無料枠で取得できる12週間より前の調整後株価にも直近分割を遡及反映する記載がある。調整後・調整前の古い株価比の変化は補助候補。正確な権利落日や個別財務の株数基準は別途照合する。
