## 継続課題 v63〜
1. D05株式数の2026-02-10の歴史的基準日を守り、より新しい公式開示と突き合わせる。株価がなければ時価総額/PER/PBRは出さない。
2. D05/O39/U11には銀行固有の連結損益・貸借項目用の解析器が必要。一般事業会社の売上高・営業利益率をそのまま使わない。
3. SGX公式・発行体PDF取得のHTTP403はアクセス拒否として即時停止。429/5xxのみ限定再試行し、古い資料を新規取得として偽装しない。
4. 独立した財務検証が未完なので、ランキングを有効化しない。親会社株主持分の同一発行体監査済み資料からの抽出と第三者クロスチェックは区別。
5. GitHub Pagesは所有者側で Settings > Pages > Build and deployment > GitHub Actions の初期有効化が未実施。ジョブの成功はPages公開成功を意味しない。
6. 変更→テスト→実PDF/公開JSON検証→GitHub保存を継続。最後に次スレッド用の短い文章を必ず付ける。
