# v548 JPXの日次権利落ち資料を仮候補の保留判定に追加

[実装](https://github.com/osawamas/value-hunter-ai/commit/6ba855c4d1834c3776812806451ede11a1e2e5fa) · [実データ検証](https://github.com/osawamas/value-hunter-ai/actions/runs/43985524391) · [Android回帰](https://github.com/osawamas/value-hunter-ai/actions/runs/43985524478)

- 公式ページの掲載中の5ファイル（11月10、11、12、13、16日公表）を取得。旧Excelの公表日、銘柄コード、普通取引の権利落日、基準日、備考、更新フラグを照合する。分割・新株落ちに当たる行を7+1+1+1+1=延べ11行検出。重複掲載を含む延べ件数で、株式併合・無償割当ての実データ行はこの5ファイルでは0件。併合の分類はテストあり。更新フラグ「●」は抽出できたが、取消・訂正の適用までは未実装。
- 公表日が取引日以前で、取引日までに権利落ちになった日次資料の該当行を保留根拠に追加。掲載がないことから対象期間の欠落を解消しない。既存の月報の該当行は優先して扱う。旧ExcelはCIの一時領域内だけに置く。
- 11月11日の仮候補30件では、月報で株数基準変更3件、日次追加の保留0件、資料不足27件。日次ページは予定中心で過去公表分は直近4営業日だけのため、10月から11月上旬の不足を閉じられなかった。公式の取得条件、訂正ルール、アーカイブの継続方法とAndroidへの接続は未確認。
- [JPXの上場廃止銘柄一覧](https://www.jpx.co.jp/listing/stocks/delisted/) と [整理銘柄指定の公式通知の例](https://www.jpx.co.jp/news/1023/20261106-11.html) は、上場廃止を伴う併合の追加照合に使える候補。ただし、上場廃止を伴わない併合を含む全国内普通株の履歴としては扱えない。前月分の資料が揃い次第、27件を再集計する。
