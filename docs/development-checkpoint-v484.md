# VALUE HUNTER AI v484

The S63 two-session check retains the earlier session's diagnostic
when the later session cannot retrieve or validate a close. Its JSON
identifies the failed session, error stage and a sanitized message.
If the first session fails, the second is not attempted.

The Actions summary receives the report even on failure. Exit status
1 indicates a retrieval or configuration failure, and 2 still means
both closes arrived but a valuation was incomplete. Fixture tests
cover a partial result and a first-session provider failure. A live
licensed endpoint and independent financial checks remain pending.
