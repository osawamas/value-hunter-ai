# v546 株価と1株指標の株数基準を照合

[実装](https://github.com/osawamas/value-hunter-ai/commit/ce30532f02509349025e49f0a8b139671c019347) · [JPX実データ検証](https://github.com/osawamas/value-hunter-ai/actions/runs/43983712430) · [Android回帰](https://github.com/osawamas/value-hunter-ai/actions/runs/43983711924)

- JPXの月報PDF「新株落・権利落等一覧」から証券コード、権利落ち日、基準日、比率を抽出。検証した2026年3月版の分割・併合・無償割当ては75件。武蔵野銀行の1:3、ピクセラの10:1、小数比率の分割1:1.05と無償割当て1:0.05も原本でテスト。
- 取引日に権利落ち済みで基準日が財務期末以降なら株数基準を要確認と判定。該当イベントが見つからなくても期末から取引日までに未提供の月があれば保留。資料が全月ある場合の戻り値は「提供資料に該当なし」で、企業の原本確認とは区別する。
- 3月版のみを渡して11月11日の仮候補30銘柄に適用し、30件すべてが資料不足として保留になることを確認。これは不足時の検証であり、30銘柄に株数変更があったという結果ではない。
- [企業会計基準第2号第30-2項](https://www.asb-j.jp/jp/accounting_standards_system/details.html?topics_id=29) のEPS遡及処理を確認。キーエンスはJPX公表の2026-11-19権利落ちを境に保留する境界テストを追加。EPSとBPSへの比率の自動適用は未実装。日本株の実機通知には接続していない。
- 次は月報の対象期間を増やし、翌月21日以降の掲載を待つ区間に日次の権利情報を使えるか検証する。
