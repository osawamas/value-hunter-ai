## 運用仕様と現状
- 私用、追加料金ゼロ。日本株・米国株監視。SGXは保留。
- 最優先：100株で10万円以下、次に単元未満株。値上がり益優先、配当は次。
- 東証：JPX日報→銘柄判定→保存→段階昇格・新規候補の無音通知を構築済み。実機で全銘柄の実監視・通知を保証していない。
- 日本株「超割安」の簡易条件: PER<=7、PBR<=0.6、比較可能な直近2期EPSがともに黒字、20%以上の減益なし、既存スコア初期85点以上。CF/同業比較が未確認であることを隠さない。PR #154。
- 米国株もSECの複数期利益・営業CFと厳格PER/PBRによる簡易最上位判定を追加済み。PR #148。
- 3段階は「割安 / かなり割安 / 超割安」。通知は基本無音、画面点灯、履歴、重複防止、再試行を志向。
- 国内外の監視網羅率と実通知到達率は、画面やクラスの存在だけでは保証できない。
- UIからの通信停止、Wi-Fiのみ、SEC連絡先設定、無音通知、画面点灯、履歴などを保持。既存機能の退行防止を必須にする。
