# VALUE HUNTER AI v356 — listed share class estimates

A personal CSV close can now produce the reference value of an individual listed class when the issuer filing supplies an exact count on that date. The result occupies a separate column and CSV field, with a filing link. Rounded, conflicting and mismatched disclosures do not produce a class value. Unlisted classes and missing quotes remain visible. Company market cap, PER, PBR and formal ranking are not populated from a partial valuation.

The browser test uses a synthetic USD 200 close for Meta on October 16, 2026 and checks its exact filed Class A count, source link and trial value. Alphabet's rounded counts remain ineligible. Continue from main toward v500 with public daily quote coverage and validated whole-company valuation.
