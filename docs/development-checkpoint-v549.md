# v549 JPX日次権利資料の更新と不一致の扱い

[実装](https://github.com/osawamas/value-hunter-ai/commit/55f77a8f2a8be7525c20cc8e418dae670c9b9eee) · [Excel内の注意書きの検証](https://github.com/osawamas/value-hunter-ai/actions/runs/43986433355) · [実データ回帰](https://github.com/osawamas/value-hunter-ai/actions/runs/43986767998) · [Android回帰](https://github.com/osawamas/value-hunter-ai/actions/runs/43986767261)

- JPXの11月16日公表XLSの注意書きはセル本文ではなく描画オブジェクトだった。描画して読んだ結果、更新の印は前営業日のファイルとの差分・追加を示し、実質上の基準日が過ぎた行は印なしで削除される。印や掲載消失だけで取消とみなさない。注意書きの描画ジョブは手動起動とし、普段の検証では公式Excelのデータを照合する。
- 銘柄・分類・基準日が一致する公表版に異なる権利落ち日があり、取引日までに既知だった場合を日次資料の不一致として保留する。取引日より後の公表版は遡って適用しない。日次の「その他」には株式無償割当て等が含まれるため、株数変更の可能性が確定するまで別理由で保留する。
- 11月10・11・12・13・16日の5版に延べ11行、照合キーで7件。異なる権利落ち日は0件。日付の矛盾・将来公表・その他の扱いは模擬データで検証。
- 11月11日の仮候補30件の再検証は、株数基準変更3、日次資料の追加保留0、資料不足27。10月と11月の月報が未掲載で、実機通知への接続も未完了。取消を自動確定する根拠と、欠けている月の資料を引き続き調べる。
