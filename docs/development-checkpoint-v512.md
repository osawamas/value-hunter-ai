# VALUE HUNTER AI v512

Toyota preflight reports missing closes, retrieval errors and snapshot
verification errors by date. HTTP status and a short reason distinguish
authentication, access, rate limits, provider errors and connection
failures. HTTP 400, 404 and 422 leave the other date available for a check.
The diagnostics do not treat a refusal as proof of the account's plan.

An incomplete preflight still fails and retains any earlier verified
result in the Actions summary. Live authenticated retrieval remains pending.
