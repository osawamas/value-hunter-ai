# 他力本願寺 · VALUE HUNTER AI 実機テスト

これは個人用の試験版。完成版や投資判断の確定版ではない。

## インストール前

- GitHub Actions の「Tarikihonganji diagnostics test APK」で**対象コミットの**単体テストとAPKビルドが成功したことを確認する。
- 端末の既存アプリに重要な保存データがあれば事前に保全する。GitHub Actionsのdebug APKは署名鍵がローカルAndroid Studioのビルドと異なる場合がある。同じアプリIDでも署名が異なると上書き更新できず、再インストールすると保存データを失う可能性がある。
- Android 9以上（minSdk 26）、Android 14/15で通知許可・電池設定・Wi-Fiを確認する。
- APKには証券口座の認証情報や追加課金APIキーを入れていないことを確認する。

## ログの取得

1. アプリ「他力本願寺」を開く。
2. 「デバッグ診断・エラー一覧」を開く。
3. 概要でエラー／再試行／通常記録を確認する。
4. 「エラー一覧」でフィルターまたは検索を使い、項目を選ぶと発生位置の詳細を見る。
5. 「詳細ログ」でスタックを確認し、「共有」から全文をコピー・共有する。
6. 共有前に必ず個人情報・認証情報の有無を点検する。典型的なトークン表記は伏せ字にするが、すべての機密情報を完全検出できるわけではない。

記録は端末内に直近7日間・最大240件保持する。例外のクラス、アプリ内スタック、ファイルと行番号を可能な範囲で記録する。OS強制終了・ANR・ネイティブクラッシュなどは取得できない場合があり、そのときはAndroid StudioのLogcatを使う。

## 検証対象

- 通信オフ／オン、Wi-Fi専用での切断・復旧
- 日本株・米国株の取得、終値・取引日・財務・株数の照合
- 通知の重複防止、無音通知、画面点灯、再起動後の履歴復旧
- 保存データの破損、日付切り替え、再試行、アプリ再起動

試験ログを共有してもGitHubのコードに自動修正は行われない。原因解析後に修正・テスト・新APK生成が必要。
